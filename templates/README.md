# 🥣 Feature Templates Directory

Welcome to the Oatmeal MVP feature templates! Here you'll find ready-to-copy templates for common app features, each following the atomic/component/service/hook/test/story structure used throughout the codebase.

## Available Templates

- **crud/**: Basic Create/Read/Update/Delete feature
- **social/**: Social feed, posts, comments, likes
- **dashboard/**: Analytics dashboard with widgets and charts
- **ecommerce/**: Product catalog, cart, checkout, and order management

## How to Use

1. Copy the desired template folder into `src/features/` and rename as needed.
2. Update the feature name, types, and business logic to fit your use case.
3. Run the appropriate generator script to scaffold additional components or services.
4. Enjoy a head start on your next MVP feature!
